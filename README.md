# AVEC — aki_lua87's Video Enhancement Components

VRChatの動画プレイヤーに、プレイリストUIとジェスチャーリモコンを追加するアセットです。

iwaSync3 / KineL V2・V3 / VizVid / YamaPlayer / ProTV 3に対応し、独自プレイヤーAVEC-SimpleScreenも同梱しています。

## 主な機能

- プレイリスト、再生キュー・履歴、ユーザーごとの保存リスト
- 壁設置・コンパクト・手持ちタブレットのUI
- ジェスチャーリモコンと操作ガイド
- 任意の拡張によるYouTube取り込み・タイトル取得、RTab連携

## 入手・使い方

- [BOOTHで入手する](https://aki-lua87.booth.pm/items/9029664)
- [導入手順・使い方](https://aki-lua87.github.io/AVEC/)

確認環境はUnity 2022.3.22f1 / VRChat Worlds SDK 3.10.5です。外部プレイヤー本体とSDKは別途導入してください。
