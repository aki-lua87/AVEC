# AVEC — Aki's Video Enhancement Components

VRChat向けの共通プレイリストUIです。iwaSync3 / KineL / VizVid / YamaPlayerに対応する
Extensionを備えています。プレイヤー本体・VRChat SDK・UdonSharpは同梱しません。

このリポジトリはアセットのソース配布用です。SDK入りのUnity 2022.3.22f1プロジェクトへ
`Assets/aki_lua87/AVEC/Core` と必要な機能・Connector・Extensionを導入してください。
未導入プレイヤーのConnectorをまとめてコピーしないでください。
UPMのGit URLから導入するパッケージではありません。
