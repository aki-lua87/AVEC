AVECは、VRChatの動画プレイヤーに**共通プレイリストUIとジェスチャーリモコン**を追加する無料アセットです。

## できること

| できること | 機能・使い方 |
| --- | --- |
| 動画を分類して並べる | [タブ付きプレイリスト](guides/playlists.md)、順番・シャッフル・単曲リピート再生 |
| 次に見たい動画を追加する | [再生キュー](guides/queue-history-saved.md)（最大32件） |
| 前に見た動画を探す | [再生履歴](guides/queue-history-saved.md)（最大32件） |
| 利用者が自分だけのプレイリストを作る | [保存リスト](guides/queue-history-saved.md)（ユーザー・ワールドごとに最大32件） |
| 手元で操作する | [手持ちタブレット](guides/tablet.md)、[ジェスチャーリモコン・操作ガイド](guides/remote.md) |
| 動画一覧を取り込む | [YouTubeチャンネル／再生リストの取り込み](extensions/youtube-import.md)（拡張） |
| ワールドをアップロードし直さずに動画一覧を更新する | [YouTubeの動画一覧の動的更新](extensions/dynamic-playlist.md)（拡張） |

## 対応するプレイヤー

iwaSync3、KineL V2・V3、VizVid、YamaPlayer、ProTV 3、および付属のAVEC-SimpleScreenに接続できます。
外部プレイヤー本体は別途導入してください。

プレイヤーごとの更新手順は[対応環境と更新](reference/compatibility.md)にまとめています。

## はじめかた

1. [インストール](getting-started/installation.md)で、必要なパッケージを選びます。
2. [プレイリストの作成](getting-started/first-playlist.md)で、配置・接続・動画登録を行います。
3. 必要に応じて[リモコン](guides/remote.md)や[YouTube取り込み](extensions/youtube-import.md)を追加します。

接続できない場合は、[困ったときは](troubleshooting.md)を参照してください。
