`AVEC-Extension-DynamicPlaylist`は、YouTubeの一覧を取り込み、動的なタイトル更新を行う任意拡張です。

## 導入する

AVEC-Coreと必要なConnectorを導入した環境へ、`AVEC-Extension-DynamicPlaylist`を追加します。

## 一覧を取り込む

1. プレイリスト設定から **AVEC-PlaylistGenerator を開く** を選びます。
2. **取り込み元** でYouTubeチャンネル／プレイリストを選び、IDまたはURLを入力します。
3. **動画一覧を自動更新** をONまたはOFFにします。
4. **取得してプレビュー** を押し、タブ名と動画一覧を確認します。
5. **このタブを挿入して保存** を押します。

チャンネルの指定には次の形式を使用できます。

- `UC…`形式のチャンネルID
- `@ハンドル`
- `/channel/ID`または`/@handle`形式のYouTube URL

チャンネルが見つからない場合は、IDまたはURLを確認してください。既存タブのURLや手動設定は自動で書き換えません。

## 「自動更新」のON／OFF

| 設定 | 保存する一覧 | ワールド内での表示 |
| --- | --- | --- |
| OFF（固定） | 取り込んだ時点の動画URLとタイトル | 保存した内容を表示。変更したい時はUnityで再度取り込む |
| ON（動的） | サービスが返す一覧の各位置を再生するURLを50枠分 | サービス側の一覧を使い、表示用のタイトルも通信で取得する |

**表示用タイトルは、各利用者がその訪問でタブを初めて選んだ時に取得**します。成功した内容は、そのワールド滞在中は再取得しません。タブを開いたまま一定時間ごとに更新する機能ではありません。取得に失敗した場合は、5秒以上空けてタブを選び直すと再試行できます。

動的な動画URLは再生時に外部サービスへ接続するため、再生する動画はその時点のサービス側の一覧に依存します。タイトル取得後に一覧が変わると、表示タイトルと再生内容が一致しない場合があります。

### タイトル取得元の設定場所

取り込み時に **動画一覧を自動更新** をONにすれば、必要な取得元URLは自動で設定されます。通常は手入力不要です。

確認する場合は **プレイリストを編集する → 対象タブ → タイトル取得API URL** を開きます。これは設定画面上の項目名です。固定リストでは空欄のままで使えます。

## タブ名

取得したYouTubeプレイリスト名がタブ名になります。名前を取得できない場合はIDを表示し、プレビューで変更できます。既存タブ名は取り込み処理で上書きしません。

## 外部サービスと制限

取り込みと動的タイトル更新には、外部サービス **`https://vrc.akakitune87.net`** への通信が必要です。サービスの停止中は取得・更新できません。

### サービスへ送信する内容

| タイミング | AVECから送信する内容 |
| --- | --- |
| Unityでチャンネルを取り込む | 入力したチャンネルID・ハンドル・チャンネルURLから取り出した識別情報、取得件数 |
| Unityでプレイリストを取り込む | 入力したURLから取り出したプレイリストID、取得件数 |
| ワールド内で動的タイトルを取得する | 対象のチャンネル／プレイリストID、件数などの取得条件 |
| 動的リストの動画を再生する | 対象のチャンネル／プレイリストIDと、一覧の何番目かを示す番号 |

AVECには、このサービスへVRChatの表示名や自分の保存リスト全体を送信する処理はありません。通信自体は、取り込み時はUnity、ワールド内では各利用者のクライアントから行われます。

:::info 動的なリストを使うときは
自動更新URLは外部サービスの稼働と **Allow Untrusted URLs** に依存します。動的リストは最大50枠です。公開ワールドでは対象URLと利用者側の設定を確認してください。
:::

保存リストへのURL追加時のタイトル取得は別機能です。[YTTLタイトル取得](yttl-titles.md)を参照してください。
