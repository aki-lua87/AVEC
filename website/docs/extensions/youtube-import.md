`AVEC-Extension-DynamicPlaylist`を追加すると、YouTubeチャンネルやプレイリストの動画一覧をAVECのタブとして取り込めます。

## 導入する

AVEC-Coreと必要なConnectorを導入した環境へ、`AVEC-Extension-DynamicPlaylist`を追加します。

## 一覧を取り込む

1. プレイリスト設定から **AVEC-PlaylistGenerator を開く** を選びます。
2. **取り込み元** でYouTubeチャンネル／プレイリストを選び、IDまたはURLを入力します。
3. **動画一覧を自動更新** をONまたはOFFにします。OFFの場合は **取得件数**（50〜500件）も選びます。
4. **取得してプレビュー** を押し、タブ名と動画一覧を確認します。
5. **このタブを挿入して保存** を押します。

チャンネルの指定には次の形式を使用できます。

- `UC…`形式のチャンネルID
- `@ハンドル`
- `/channel/ID`または`/@handle`形式のYouTube URL

プレイリストは、プレイリストIDまたは`list=…`を含むYouTube URLで指定します。動画単体のURLだけでは取り込めません。

取り込んだ一覧は新しいタブとして追加されます。既存タブのURLや手動設定は自動で書き換えません。

## 「自動更新」のON／OFF

| 設定 | 保存する一覧 | ワールド内での表示 |
| --- | --- | --- |
| OFF（固定） | 取り込んだ時点の動画URLとタイトル | 保存した内容を表示。変更したい時はUnityで再度取り込む |
| ON（動的） | 外部サービスの一覧の各位置に対応する再生URLを50枠分 | サービス側の一覧に応じた動画を再生し、表示用タイトルも通信で取得する |

同じ一覧を使い続ける場合はOFF、YouTube側の一覧の変更に追従させたい場合はONにします。ONの場合は **Allow Untrusted URLs** が必要です。

更新タイミング、表示と再生の関係、制限は[動画一覧の動的更新](dynamic-playlist.md)を参照してください。

## タブ名

チャンネルは取得したチャンネル名、プレイリストは取得したプレイリスト名がタブ名になります。名前を取得できない場合はIDを表示し、プレビューで変更できます。既存タブ名は取り込み処理で上書きしません。

## 外部サービスと取得できない場合

取り込みには、外部サービス **`https://vrc.akakitune87.net`** への通信が必要です。

| 取り込み元 | Unityからサービスへ送信する内容 |
| --- | --- |
| チャンネル | 入力したチャンネルID・ハンドル・チャンネルURLから取り出した識別情報、取得件数などの取得条件 |
| プレイリスト | 入力したURLから取り出したプレイリストID、取得件数 |

取得できない場合は、ID・URLとYouTube側の公開状態を確認してください。空のプレイリストや非公開プレイリストは取り込めません。サービスの停止中は取り込めないため、時間を空けて再試行してください。

保存リストへのURL追加時のタイトル取得は別機能です。[保存リストのタイトル取得](yttl-titles.md)を参照してください。
