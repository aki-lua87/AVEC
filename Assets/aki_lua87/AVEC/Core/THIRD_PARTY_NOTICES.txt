## Hosted playlist service

The optional YouTube import and dynamic-title features contact
https://vrc.akakitune87.net, a service operated by AVEC's author.
Server project: https://github.com/aki-lua87/vrc_video_playlist_server
Import sends channel or playlist IDs to this service; dynamic URLs and title
updates depend on its availability. The server implementation is separate
from the Unity source distribution and is not licensed by AVEC's LICENSE.txt.
