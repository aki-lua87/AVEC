# AVEC DynamicPlaylist Extension

必要なパッケージ: AVEC-Core / AVEC-Playlist。接続して再生するには対応Connectorとプレイヤー本体も必要です。

本体の「動的プレイリストを開く」、または`Tools > AVEC > Extensions > Dynamic Playlist`から開きます。

1. 挿入先のPlaylistData（.asset）を選択します。
2. YouTubeチャンネル／プレイリストのIDかURLを入力します。
3. 動的URLのON／OFFを選び、「取得してプレビュー」を押します。
4. タブ名・動画一覧を確認して「このタブを挿入して保存」を押します。

既存タブは保持して末尾に追加します。共有データならすべての参照UIへ反映します。本体の編集画面に未保存変更がある場合は、先に保存または破棄してください。失敗時はプレイリストを書き換えません。挿入はUndoできます。

チャンネルの動的枠は20件、プレイリストの動的枠は取得時の件数です。ワールド実行中に増えた枠は自動で増えません。タイトルだけはタブ選択時に更新します。取得した一覧が短くなった場合は元の表示名へ戻します。ワールドの終了通知がないライブ配信や単曲リピートは、キューの自動遷移対象になりません。

取り込みは`https://vrc.akakitune87.net`にチャンネル／プレイリストIDを送ります。動的チャンネル登録はPOST、一覧・目次はGETです。バックエンドは配布物に含みません。動的再生URLとタイトル取得はサービスの稼働とAllow Untrusted URLsに依存します。固定URLで取り込めば、実行時の動的タイトル取得は行いません。

Extension未導入の本体に取り込みUI・HTTP取得処理はありません。既存データの動的メタデータは互換のため保持します。
