# AVEC-SimpleScreen

AVEC-Core同梱の独自プレイヤーです。VRChat SDKのAVPro再生コンポーネントを利用し、モニター・音源・最小UI・同期処理・Playlist／Remoteコネクターを含みます。第三者プレイヤーのソース／Prefabは使用しません。SDK自体は同梱しません。

## 配置と接続

1. SDK Worlds 3.10.5入りのWorldプロジェクトにAVEC-Coreを導入します。
2. Projectから`Assets/aki_lua87/AVEC/Prefabs/AVEC-SimpleScreen.prefab`をHierarchyへドラッグ＆ドロップして配置します。
3. 必要なPlaylist／RemoteのPrefabを配置し、それぞれのSetup Inspectorでこの`SimpleScreenPlayer`を接続先に選択します。追加Connectorは不要です。
4. ワールドにEventSystemがあることを確認します。モニターの正面はローカル-Z側です。Prefabの初期サイズは幅3.2m×高さ1.8mです。ルートを移動・回転・一様スケールして配置できます。

既存プレイヤーやシーンを自動で置き換える処理はありません。新規配布Prefabの作成処理は既存Prefabの上書きを拒否します。通常の編集でUIやPrefabを再生成する必要はありません。

## モニターの操作

- モニターにレイを当てると操作パネルを表示します。レイが外れて2秒後に非表示になります。ドラッグ・URL入力中は表示を維持します。
- 進捗バーをドラッグして離すとシークします。ライブ配信や長さを取得できない動画では操作できません。
- 音量バーとスピーカーアイコンは自分の音量／ミュートだけを変更します。PlaylistやRemoteからの変更も同じ値へ反映します。
- URLを入力し、確定またはLOADで再生します。キューへの追加ではなく、そのURLへ再生を切り替えます。直前のPlaylist連続再生を解除し、履歴に記録します。
- 読み込み中、権限不足、URLエラー、再試行状況をパネル上部に表示します。失敗して再試行が終わった場合はURLを再送信してください。

再生・一時停止・停止・リピート・先頭から再生・Playlistの次／前などはPlaylist／Remote側から操作します。独自の内部プレイリストは持ちません。標準キーボードをジェスチャーから直接開く機能は未実装です。

## 同期と復旧

- 同期する値はURL、動画の世代、再生状態、基準位置、サーバー基準時刻、単曲リピートです。表示状態と音量は同期しません。
- 操作者が所有権を取得し、動画の準備完了後に再生開始時刻を確定します。途中参加者や読み込みの遅いクライアントは準備完了後に同じ時刻基準へ追従します。
- 2秒ごとに再生位置を確認し、初期値1.25秒を超えるずれを補正します。所有者は状態を10秒ごとに再送し、送信失敗時も再試行します。
- 所有者が退出しても受信済みの時刻基準を保持します。読み込み中に所有者が交代した場合は、新しい所有者の準備完了後に再生を開始します。
- 一時的な失敗と45秒の読み込みタイムアウトは、5.5秒以上の間隔を空けて最大3回再試行します。アクセス拒否・無効URLは自動再試行せず理由を表示します。エラーはローカル表示で、他の正常な視聴者の再生を停止しません。
- `masterOnly`を有効にすると再生操作をMasterまたはインスタンス所有者に制限します。ローカル音量操作は引き続き可能です。
- ライブ配信ではURLと再生状態を共有しますが、配信側のバッファによる遅延差をシークで解消することはできません。

初期音量、補正閾値、タイムアウト、再試行回数、操作パネルの表示待ち時間はInspectorで変更できます。音源は初期設定で3D／距離25m、解像度上限は1080です。

## 確認範囲と手動確認

実装時にC#／UdonSharpコンパイル、編集時のPrefab参照・UIイベント・音声映像出力・Playlist／Remote接続・Core収録対象を確認済みです。`Tools > AVEC > SimpleScreen > Validate Prefab`で編集時の参照チェックを再実行できます。Playモード／VRChatでの自動動作テストや別プロジェクトへのインポートは行っていません。

VRChatで以下を手動確認してください。

- VR／デスクトップで、レイによるパネル表示・非表示、シークのドラッグ、URL入力中の表示維持。
- モニター・Playlist・Remote間の音量とミュートの一致、他ユーザーの音量が変化しないこと。
- 2人以上でURL変更、シーク、一時停止／再開、停止、単曲リピート、Playlist／キューの連続再生。
- 再生中／一時停止中／読み込み中の途中参加と所有者退出。
- 無効URL、アクセス拒否、一時的失敗、タイムアウト、再試行上限後のURL再送信。
- シーク可能な通常動画とライブ配信。Android対応が必要な場合は対象端末で映像・音声・URL互換性も確認。

VRChat側のURL許可設定、動画サービスの制限、PC／Androidでの対応URL差はSDKの再生仕様に従います。

Coreへの収録設定はRelease Builderに追加済みです。配布パッケージは必要なときにまとめて生成してください。
