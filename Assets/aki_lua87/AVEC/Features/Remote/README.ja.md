# AVEC Remote

持ったリモコンで上下左右のジェスチャーを描き、選択した動画プレイヤーを操作するAVECの機能です。共通Core、Remote機能、プレイヤーごとのConnectorに分けています。各リモコンは1台のプレイヤーに接続します。

## 導入

1. Unity 2022.3.22f1 / VRChat Worlds SDK 3.10.5のプロジェクトにAVEC-CoreとAVEC-Remoteをインポートします。
2. 使用する動画プレイヤー本体と、対応するAVEC-Connector-プレイヤー名-Remoteだけを導入します。Remote機能だけでも、カスタムUdonイベントのジェスチャーリモコンとして使えます。
3. `Prefabs/CommonGestureRemote.prefab` をシーンに配置します。
4. ルートの `RemoteSetup` Inspectorで接続先を選択します。候補が1件なら自動接続、複数件なら候補ボタンから選択します。手動設定は自動で上書きしません。Prefabアセットにはシーンへの接続先を保存しません。
5. 次／前の動画、再生順、タブ操作にはAVEC-Playlistと対応するPlaylist Connector、AVEC-Extension-PlaylistRemoteも導入し、同じプレイヤーに接続したPlaylistViewを選びます。
6. 感度や見た目は「感度・表示・画面設定」で調整します。機能の割り当ては「ジェスチャー設定を編集」で変更します。

シーンへ配置したPrefabの接続・設定変更はUndoとPrefab overrideに対応します。Play / Build前にジェスチャー設定を自動反映します。「接続を修復・設定を反映」でも反映できます。Coreの「Generate Assets」はProgram AssetとU#アセンブリ定義を生成する開発用メニューです。配布物には生成済みのアセットを含めています。

## 操作

持つ → トリガーを引く → 描く → 候補名を確認してトリガーを離す、の順に操作します。DesktopではAuto Hold付きのリモコンを持ち、左クリックを押しながら視点を動かします。途中で手放した場合、一致しなかった場合、8秒を超えた場合はキャンセルします。

| 初期ジェスチャー | 操作 |
|---|---|
| → | 次の動画 |
| ← | 前の動画 |
| →↑ | 音量 +10ポイント |
| →↓ | 音量 -10ポイント |
| ↑↓ | 音声ミュート／解除（自分） |
| ↓↑ | 1動画リピート／解除 |

一致中はトレイルが緑になり、先端に機能名を表示します。判定中には機能を実行せず、解放時に1回だけ実行します。そのため `→↑` の途中に `→` を通っても次の動画へ飛びません。ジェスチャーは入力開始時の視線を基準とし、VRでは頭の移動分を除いたリモコン先端の動きを判定します。最小移動距離は初期値5.5cm、VRではアバターの身長に合わせて補正します。曖昧な斜め入力は候補を取り消し、上下左右にはっきり動いたら判定を続けます。最大3ステップ、トレイルは最大256点です。

音量の初期変更量は0.1です。プレイヤー本体の最小・最大音量制限は維持します。例えばiwaSync3で最大音量が0.5なら、それ以上には上がりません。`volumeStep` を変えた場合は表示名も合わせて編集してください。

## ジェスチャー設定と汎用イベント

`DefaultGestures.asset` を複製して設定を作成できます。`Assets > Create > AVEC > Remote > Gesture Data` から新規作成もできます。同じGestureDataを複数のリモコンで共有できます。Inspectorで上下左右を選択して登録し、表示名と操作を選択します。重複、空の名前、4ステップ以上、同方向の連続指定はエラーになります。

選べる操作は、次／前の動画、音量UP/DOWN、再生停止、一時停止、再開、ミュート切替、リピート切替、再生順切替、次／前のタブ、カスタムイベントです。Inspectorの方向欄で上下左右を最大3ステップ選択します。同方向の連続は1ステップとして扱います。

照明やミラーなどへの利用では `CustomEvent` を選び、イベント名を設定します。RemoteSetupの「カスタムイベントの接続先」に対象のUdonBehaviourを指定します。イベントはローカルで1回呼び出します。対象側の同期・権限はそのUdonの責任です。複数の対象を操作する場合は接続先のUdonを中継役にします。

## 同期・プレイリスト

- 同じプレイヤーへ接続した複数のリモコンは1つのRemoteTargetを共有します。音量とミュートは利用者ごとのローカル状態です。映像のON/OFF機能は削除しました。
- VRでは掴んだ位置・角度を維持し、グリップを離すと手放します。Desktopでは入力イベントに必要なAuto Holdを起動時に有効にします。[VRC Pickup仕様](https://creators.vrchat.com/worlds/components/vrc_pickup/)
- リピートは接続先の単曲ループを切り替えます。Playlist連携時はPlaylist側の再生設定・表示も更新します。
- 次／前の動画、停止、一時停止、再開、再生順はネイティブプレイヤーの操作権限と同期方式に従います。トレイル、候補名、タブ選択はローカルです。リモコンの物理位置はVRC Object Syncで同期します。
- 次／前の動画はCommonVideoPlaylistが持つ現在の再生位置を使います。順番再生では同じタブ内の有効なURLを選び、先頭／末尾で停止します。再生位置がない場合はリモコンに指定したPlaylistViewの選択タブの先頭から開始します。
- ランダム再生時の次／前は同じシードで決まる順序を進み／戻ります。手動で選んだ動画を新しい一巡の開始位置にします。「前」は動画の視聴履歴ではありません。ランダム順の端でも手動操作は折り返しません。
- URLの読み込み開始から5.1秒以内の次／前は待機表示にします。再生指示を渡したことと、実際の動画読み込み成功は別です。読み込み結果は接続先プレイヤーで確認してください。
- KineL 2.5.5には共通の音量APIがないため、同製品のUIと同じAudioSource.volume経路を使い、対応するSlider表示も更新します。ミュートはネイティブAudioModuleの状態・アイコンと合わせます。

## 配布と検証

`Tools > Common Assets > Release Builder`で必要な機能・Connector・Extensionを選んで出力します。`Tools > AVEC > Remote > Export Packages`も同じ画面を開きます。通常の編集ごとに出力する必要はありません。プレイヤー本体とシーンは含めません。未導入プレイヤーへの型参照を機能へ持ち込まないため、Connectorを分離しています。Release Builder未導入の環境では出力用ツールを別途導入してください。

検証済み範囲は `VALIDATION.ja.md` を参照してください。VRChat実機でのVR操作感、左右のコントローラー、複数人同期、Quest/Androidの実機動作は未確認です。
