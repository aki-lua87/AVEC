## Gesture拡張・ローカル位置・操作一覧（2026-10-06）

- 初期設定にPause(↑)、Resume(↓)、Restart(←→)、OrderedPlayback(↑←)、RepeatOne(↓↑)、ShufflePlayback(↑→)を設定。再生モードは独立した直接設定。旧Toggle操作はデータ互換用に保持。
- Restartは4種類のネイティブシークAPIを使用し、通常動画を0秒へ移動して再開。ライブ／未ロードは拒否。KineLのResumeは既に再生中なら時計をリセットせず成功扱い。
- YamaPlayerのローカル音声操作をUIのactive状態・Handler参照から分離し、BeforeUserChangeMute／Volumeを尊重。要求値を一度だけ計算し、初期化による上書きに備えて翌フレームに絶対値を再適用。同じミュート操作を2回反転させない。報告された初回不具合は実機再現・解消確認未実施。
- リモコンPrefabと現在の4台からVRCObjectSyncを除去。GestureRemoteとBacking UdonのSyncMethodはNone。所有権移動でローカルの入力をキャンセルする処理を除去。
- CommonGestureGuide.prefabをRemote/Prefabsへ追加。ローカルPickup、11件の初期Gestureと説明、レイドラッグ用スクロールバーを含む。同じGestureDataを設定し、Inspector・データ編集・Play/Build前にテキストを更新する。Remote配布フォルダに含まれるが配布パッケージは今回生成していない。
- C#／UdonSharpコンパイル成功。既存4台の接続・感度・トレイル・候補表示参照・色・位置を保持。Playモードには入っていない。

手動確認: 入室直後のYamaPlayerミュート／音量（本体UIの操作前、UIを閉じた状態も） → 一時停止／再生 → 同じ再生Gestureの繰り返しで再生位置が変わらないこと → 再生中・一時停止中の初めから再生 → 各モードを繰り返して解除されないこと → ロック時の拒否 → 他人が持っても自分のリモコン位置が動かないこと → 操作一覧の末尾までスクロール → 独自GestureDataで一覧が更新されること。
