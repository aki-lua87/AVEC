# 検証記録 (2026-10-04)

0.2.0ではコンパクトなプレイリストと4方向のデモシーンへの接続を、このプロジェクト内で編集時に確認しました。C# / UdonSharpコンパイルを確認し、別プロジェクト確認、Playモード、ランタイム自動テスト、配布物の出力は行っていません。以下は0.1.0時点の検証履歴です。新しいプレイリスト操作との組み合わせはデモシーンで手動確認してください。

Unity 2022.3.22f1、VRChat Worlds SDK 3.10.5で検証しました。

- Editor検証40項目: 設定のベイク、不正入力、方向認識、接続先の検出、複数候補の選択、共有接続、プレイリストの境界を確認。
- ClientSimの実Udon VMで各プレイヤー27項目: トリガー解放時のみ実行、二重実行防止、音量上下と上限下限、キャンセル、トレイル、ローカルOFF/ONとミュート復元、タイムアウト、カスタムイベント、プレイリストの次/前・待機制限・タブ・再生順・停止要求を確認。
- Coreのみ、および各Extensionの計6構成で、無関係なプレイヤーへの参照を除いたC#コンパイルを確認。
- 動画プレイヤーとCommonVideoPlaylistが存在しない別UnityプロジェクトへCoreのみをインポートし、UdonSharpコンパイル、PrefabのProgram・トレイル・ラベル・先端参照、初期6ジェスチャーを確認。
- 配布7パッケージの収録パス、GUID参照、メタデータを確認。日本語ラベルとトレイルのプレビュー画像を確認。

詳細結果は配布ZIPの検証記録に含めています。動画操作の検証はネイティブプレイヤーへの要求と状態遷移までであり、外部動画の読み込み成功を保証するものではありません。

VRChat実機でのVR操作感、左右コントローラー、複数ユーザー間の同期、Quest/Android実機は未確認です。感度は実機で調整してください。停止・再生・プレイリスト操作の権限と同期は接続先の仕組みに従います。ローカルOFFは映像と音声を隠す機能で、デコード停止や同期停止ではありません。
